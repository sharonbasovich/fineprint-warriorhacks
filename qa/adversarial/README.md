# Adversarial regression set

These cases were authored after the round-3 repair as a challenge set distinct
from `qa/corpus/` (which holds the regression cases derived from the
independent reviewer's reported failures). Expectations were written from the
source text before running the harness — not tuned to the parser's output.

Same authorship caveat applies, and it applies even more strongly now: these
cases were visible while the round-4 conservative parser was being tuned, so
they are part of the regression corpus — regression evidence that the parser
behaves as designed on them — and are **not** held-out or independent
verification of accuracy.
