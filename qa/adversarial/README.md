# Fresh adversarial set

These cases were authored **after** the round-3 repair, as a predeclared
challenge set distinct from `qa/corpus/` (which holds the regression cases
derived from the independent reviewer's reported failures). Expectations were
written from the source text before running the harness — not tuned to the
parser's output. Same authorship caveat applies: author-built cases are
regression evidence, not independent verification.
